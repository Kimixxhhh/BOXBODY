Field Kit — Godot 4.7 C# 最小原型

运行
1. 本机直接双击 RunGame.cmd，会先编译，再启动游戏。
2. 或使用 Godot 4.7 .NET 版打开 project.godot，按 F5。
3. 已使用本机 Godot 4.7.1 .NET 和 .NET SDK 10 验证。
   工程目标框架为 net10.0；普通非 .NET 版 Godot 无法运行 C# 脚本。

操作
WASD / 方向键：移动。
鼠标：持枪朝向平滑跟随鼠标，跟随速度由武器“转动惯性”系数控制。
R：从背包中寻找对应弹药，在武器配置的换弹时间结束后装填（默认 2.65 秒）；重复按键不会重启动作或重复扣弹药。
E：走近武器箱后打开购买列表，可购买武器或中型子弹；再按 E 关闭。
1 / 2：切换背包上方两个槽位中已购买的武器；空槽位不响应。
Tab：在任意位置打开 / 关闭背包；武器箱打开时按 Tab 切换到背包。
背包物品：按住鼠标左键拖到另一个小槽位；空槽直接移动，已有物品则交换位置。
Esc / 关闭按钮：关闭当前列表或背包。
列表或背包打开时暂停人物移动及转向，相机始终锁定人物。

当前范围
角色：assets/characters/Millitia.glb（按用户指定文件引用）。
武器箱：assets/environmentObjects/weapon_box_laptop.glb。
白色平面、基础光照、角色与箱子碰撞。
固定俯视正交相机，视野范围为 11 米（较初版扩大 37.5%），移动方向对应画面方向。
箱子持续白色外轮廓高光，包含箱顶笔记本电脑的轮廓。
靠近箱体表面 1.35 米以内可互动，列表包含武器与弹药，并显示名称、数量和价格。
每次进入游戏拥有 5000$ 初始资金，人物空手，两个武器槽位均为空；资金显示在 HUD、武器箱和背包中。
购买成功后扣除价格，依次装入第一个空闲武器槽位并立即持用；允许在两个槽位中购买同款武器。
资金不足或两个武器槽位已满时禁用购买并显示原因，不扣款、不替换已有武器；离开箱子或关闭列表也无法购买。
AK-47 初始价格为 2500$，可通过独立武器维护工具修改。资金与装备为本局状态，重新进入游戏重置。
中型子弹：每份 250$，总弹药量固定为 40 发，购买时剩余弹药量为 40 发；每份独占下方 16 个小物品槽位中的一格，不合并堆叠。
购买弹药不占用上方武器槽位。背包物品栏已满或资金不足时阻止购买，不扣款。
每份弹药独立记录剩余数量；物品槽显示“剩余 / 总量”，悬停或点击可查看两个属性。
中型子弹图标直接使用 assets/weapons/ammo/bullet_ak_triple.glb，在独立视口中渲染；所有同类物品和拖动预览共用一份图标纹理。
背包内拖动保留物品实例、总量和剩余弹药，不拆分、不合并、不改变资金；拖到槽位外或武器槽位时取消，关闭背包也会取消未完成拖动。
调整位置后换弹按新的槽位顺序使用弹药。如果换弹在拖动期间耗尽该物品，会取消拖动，避免恢复已消耗的弹药。
新购武器弹匣为空；AK-47 使用中型子弹，弹匣容量由武器配置决定（默认 30 发）。两把同款武器独立保存弹匣余量。
换弹按物品槽顺序寻找匹配类型的弹药，可连续从多份物品补足弹匣；只消耗缺少的数量，备弹不足时仅装入现有数量。
弹药在动画完成时才扣除，剩余弹药量不会低于 0；用完的物品移除并释放原槽位，后续购买优先填入首个空槽。
弹匣已满或没有对应弹药时不开始换弹，并显示原因；切换或购买另一把武器会取消进行中的换弹，不消耗弹药。
HUD 显示当前武器的弹匣余量、容量和匹配的背包备弹；背包上方两个武器栏显示各自弹匣余量和容量。
购买后从武器配置的 scenePath 实例化武器场景，默认 scenes/weapons/AK47.tscn 引用 assets/weapons/rifle/AK47.glb。
空手时双臂自然下垂并随步伐摆动；持枪时右手握枪柄、左手托护木。
持枪实例比例：宽度 1.8、高度 1.2、长度 1.17；相比初版，枪身宽度加倍，长度增加 30%。
枪身相对放大后的初始持枪位置向前移 12 厘米，双手及换弹动作随握持点同步移动。
双臂沿长度方向延长 15%，关节与手掌握持点同步调整，原始模型文件不变。
移动时双脚交替迈步，身体轻微起伏，双手持续贴合枪械；支持侧移和倒退。
换弹包含倾斜枪身、左手取出弹匣、装回弹匣、拉动枪机及恢复持枪姿势。
已实现购买、两个槽位的装备切换、持枪、真实弹药数量与装填判定；射击和弹道尚未实现。
打开武器箱列表时不响应新的 R 键；已开始的换弹动作正常完成。
背包沿用现有深灰绿面板、圆角、细边框与中文字体：上方两个武器栏及配件位，下方 2 × 8 个物品格。
两个武器栏均根据实际购买结果显示内容，直接实例化 scenePath 武器场景，在独立 3D 视口中渲染；配件为空，物品栏显示购买的弹药。
背包关闭时停止预览渲染，打开时刷新；预览实例禁用游戏脚本，不参与实际玩法。
空武器槽的弹药数量以横线显示，已购买武器显示实际数量。
物品格支持悬停 / 点击查看栏位说明，也支持拖动移动和交换；弹药由换弹自动使用，不包含场景拾取。
背包与武器箱互斥，背包打开时不响应 E 互动和新的 R 换弹，适配最低 800 × 600 窗口。

scripts/CharacterAnimator.cs：双臂两段关节跟随、持枪姿势和移动动画，保留原始 GLB 文件。
scripts/HeldWeaponAnimator.cs：现有 AK 模型挂载与换弹动画时间轴。
scripts/FollowCamera.cs：相机锁定。
scripts/WeaponCrate.cs：互动距离。
scripts/Prototype.cs：场景与交互协调。
scripts/InteractionUi.cs：武器与弹药价格列表、购买和换弹反馈、余额与弹药数量刷新。
scripts/InventoryUi.cs：背包布局、物品拖动与交换、武器和物品 3D 预览、自适应尺寸。
scripts/WeaponModelPreview.cs：独立预览场景、自动构图和光照。
scripts/InventoryIcon.cs：背包配件及空栏位的矢量图标。
scripts/CrateOutline.cs + shaders/crate_outline.gdshader：白色屏幕空间外轮廓。

验证
dotnet build FieldKit.csproj
Godot .NET 可执行文件 --headless --path . -- --smoke-test
省略 --headless 可额外检查实际渲染、轮廓和窗口缩放，并保存 artifacts/ 截图。
scripts/PrototypeSmokeTest.cs 仅在传入 --smoke-test 时运行，不影响正常游戏。
额外传入 --ammo-storage-test 可检查 16 格弹药购买、物品满格和小窗口显示。
额外传入 --inventory-drag-test 可用真实鼠标事件验证移动、交换、取消、换弹同时消耗以及缩放后的拖动，并保存图标及拖动截图。
额外传入 --weapon-audio-test 可验证换弹音效计时、重叠播放、重复按键、切枪取消及枪声播放接口；测试使用内存中的音频样本，不修改真实配置。
额外传入 --reload-timing-test 可验证快慢换弹、完整动画与双手同步、装填时刻、切枪取消和重复按键。

其他电脑运行 RunGame.cmd 时，可设置 GODOT_DOTNET 环境变量为 Godot .NET 的路径。
misc/、zips/ 为原模型制作文件，使用 .gdignore 防止被当作游戏资源导入。

独立武器维护工具
双击 RunWeaponEditor.cmd。这是独立的 Windows 桌面工具，不启动游戏，不在游戏内显示。
3D 预览在后台调用 Godot 读取武器场景网格，再由桌面界面的 Viewport3D 直接绘制。
预览支持拖动旋转、滚轮缩放、双击复位；切换场景或重新载入后刷新。
后台读取使用 GODOT_DOTNET 指定的引擎；未设置时使用本机 D:/godotCs 中的 Godot .NET。
资源需先在 Godot 中导入；引擎不可用时会显示预览错误，参数编辑仍可使用。
需要 .NET 10 SDK（启动脚本负责编译）和 Windows Desktop Runtime；本机已安装。
也可直接运行 tools/WeaponWorkbench/bin/Release/net10.0-windows/WeaponWorkbench.exe。
工具自动定位本工程，亦支持 --project "工程绝对路径"。

使用流程：左侧搜索或选择武器 → 编辑属性 → 保存全部（Ctrl+S）。
切换武器保留未保存草稿；红色字段会阻止保存，包括其他武器的无效草稿。
“撤销本武器修改”恢复上次保存值；重新载入及关闭窗口时，会询问如何处理未保存修改。
配置位于 data/weapons.json（schemaVersion 4），目前只登记 AK-47；其他武器条目已移除，原始模型资源保留。
旧版配置需要将 schemaVersion 改为 4，并在每把武器的 stats 中添加 price 整数价格后使用；缺少价格时拒绝载入，避免意外免费购买。
AK-47 已有的调参数值保持不变；转动惯性默认系数为 10。
武器场景支持输入工程内 res:// 路径或“选择文件”，保存时检查路径、格式和文件是否存在。
武器场景路径参与未保存提示、撤销和保存；图标字段已移除，显示武器无需单独图片。
“05 武器音效”可选择或清空枪声，并添加、删除多条换弹音效；每条都有独立的“播放延迟 · 秒”。
音效支持工程内的 WAV / OGG / MP3。先将文件放入工程，再使用“选择文件”；RunGame.cmd 启动时会导入新资源。
音效路径、列表与延迟参与草稿、撤销、保存和备份；文件缺失、格式不支持、负数或无效延迟会阻止保存。
保存使用临时文件原子替换，并在 data/weapons.json.bak 保留上一次完整配置。
文件在其他窗口被修改时会拒绝覆盖，可先保留需要的数值，再重新载入。
备份恢复：关闭维护工具后，将 .bak 文件复制覆盖 weapons.json，再重新打开工具。

属性定义（工具与游戏共用 scripts/Weapons/ 中的数据类型和校验规则）
枪声：武器的 gunshotSoundPath，留空表示静音；提供 PlayGunshot 播放接口，待开火玩法接入。
换弹音效：武器的 reloadSounds 列表，每条包含 soundPath（音效路径）和 delaySeconds（非负秒数）。
所有延迟从本次换弹开始计算，而非上一条音效结束后计算；0 为立即播放，相同延迟可以重叠播放，列表可按任意时间顺序填写。
例如延迟分别为 0、0.8、1.9，表示在换弹开始、开始后 0.8 秒、开始后 1.9 秒各播放一次。
成功开始换弹后按时间播放；缺少弹药、弹匣已满或重复按 R 不会重新触发音效。
切换武器会停止正在播放和等待中的换弹音效；下一次换弹重新计时。正常完成换弹不会截断音效，超过动画时长的延迟仍会按配置播放。
当前工程未提供枪声或换弹音频，AK-47 默认枪声为空、换弹列表为空；选择实际文件后生效。旧版 schemaVersion 4 缺少这两个字段时同样默认静音。
对应弹药：ammoType，当前为 Medium（中型子弹），换弹仅使用该类型；武器维护工具可显示和保存此字段，旧版 schemaVersion 4 未写该字段时默认中型子弹。
购买价格：price，单位 $，范围 0–1000000 的整数；0 表示免费，仍需通过武器箱购买并占用武器槽位。
伤害值：单次命中的基础伤害，非负。
减速值：敌人移速降低百分比，0–100；不包含减速持续时间。
击退值：沿命中子弹方向施加的速度，单位米/秒，非负；方向由未来命中逻辑提供。
开火后冷却时间：两次射击的最短间隔，单位秒，至少 0.001；射速为 60 / 冷却时间（发/分钟）。
单发或连发：SemiAuto 为每次按下开火一次；Automatic 为按住持续开火，并遵循冷却时间。
弹夹容量：正整数。
换弹时间：reloadDuration，单位秒，可在“02 开火与装填”中设置，范围 0.001–3600；越小换弹越快，默认 2.65。
整段换弹动画按此时间等比例变速，包括枪身、弹匣、枪机及双手；动画结束时才从背包扣除对应弹药并补充弹匣。
例如设为 1.325 秒时动画为原来的 2 倍速，设为 5.3 秒时为原来的半速。移动和转向速度不受影响。
本次换弹开始时确定时长，重复按 R 不会重置；切换武器会取消，下次换弹使用新武器的配置。
旧版 schemaVersion 4 未设置 reloadDuration 时保留 2.65 秒。音效延迟仍按每条 delaySeconds 的实际秒数执行，可独立调整。
移动惯性：这里定义为持枪移动速度惩罚百分比，0–100；速度 = 基础速度 × (1 - 惯性 / 100)。
转动惯性：turnFollowSpeed，是乘在 delta 上的跟随系数 k，范围 0–1000，默认 10。
每帧按 LerpAngle(当前朝向, 鼠标目标朝向, 1 - Exp(-delta * k)) 沿最短角度平滑跟随。
角度差越大，每帧转过的角度越大；系数越大跟随越快；0 表示不转向，不是瞬间转向。
该公式使用帧间隔，30/60/120 FPS 下对固定目标的跟随速度一致；打开界面时仍停止转向。
子弹飞行速度：米/秒，必须大于零。
子弹散布最大值 / 最小值：偏离瞄准方向的半角，单位度，0–180，最小值不能超过最大值。
子弹散布增加值：每开一枪增加的角度，单位度/发，增加后不超过最大值。
散布减少值：度/秒；最后一枪经过冷却时间后开始下降，不低于最小值；0 表示不恢复。
散布恢复计算只使用当前帧位于冷却结束后的时间，避免跨冷却边界提前恢复。
武器场景：scenePath，支持 TSCN / SCN / GLB / GLTF，根节点必须为 Node3D；购买或切换武器时加载为持有武器。
默认场景保留现有 AK 的弹匣、枪机及换弹表现；替换自制模型时需自行匹配握持点及比例。
背包和维护界面均通过 scenePath 展示 3D 模型。
桌面维护预览读取网格和基础材质颜色；自定义着色器效果以 Godot 游戏内预览为准。

游戏启动时读取这份配置作为武器箱商品列表，购买后将属性应用到当前持有武器。价格、移动惯性和转动惯性均已实际生效。
射击、飞行子弹和敌人减速/击退尚未实现；已实现弹药购买、背包消耗与弹匣装填，其余属性作为可维护数据及共用计算接口提供。
保存后需重启游戏读取新值，不会在后台改变已经运行中的游戏。
导出游戏时，需要将 data/*.json 加入非资源文件导出过滤器。

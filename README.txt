Field Kit — Godot 4.7 C# 最小原型

运行
1. 本机直接双击 RunGame.cmd，会先编译，再启动游戏。
2. 或使用 Godot 4.7 .NET 版打开 project.godot，按 F5。
3. 已使用本机 Godot 4.7.1 .NET 和 .NET SDK 10 验证。
   工程目标框架为 net10.0；普通非 .NET 版 Godot 无法运行 C# 脚本。

操作
WASD / 方向键：移动。
鼠标：持枪朝向平滑跟随鼠标，跟随速度由武器“转动惯性”系数控制。
鼠标左键：持握手雷时投掷手雷；其余情况射击。单发模式每次按下一枪，连发模式按住持续开火。先购买武器和弹药，再按 R 装填。
R：从背包中寻找对应弹药，在武器配置的换弹时间结束后装填（默认 2.65 秒）；重复按键不会重启动作或重复扣弹药。
E：走近武器箱后打开购买列表，可购买武器、中型子弹或手雷；再按 E 关闭。
1 / 2 / 鼠标滚轮：切换背包上方两个槽位中已购买的武器；空槽位不响应。滚轮上为上一把、下为下一把，只在已装备的武器之间循环并跳过空槽。切换时旧枪先收回、新枪再拿出，期间不能开火或换弹。
G：短按（松开）拿出背包中顺序最靠前的投掷物；长按约 0.28 秒打开投掷物轮盘，移动鼠标选择种类后松开 G 拿出选中种类。手雷就绪后按鼠标左键投掷。手雷已在手中时短按 G 收起并重新取出原武器，不消耗手雷；长按 G 可在轮盘中切换手持种类。
Tab：在任意位置打开 / 关闭背包；武器箱打开时按 Tab 切换到背包。
背包物品：按住鼠标左键拖到另一个小槽位；空槽直接移动，已有物品则交换位置。
Esc / 关闭按钮：关闭当前列表或背包。
列表或背包打开时暂停人物移动及转向，相机始终锁定人物。

当前范围
角色：assets/characters/Millitia.glb（按用户指定文件引用）。
武器箱：assets/environmentObjects/weapon_box_laptop.glb。
白色平面、基础光照、角色与箱子碰撞。
固定俯视正交相机，视野范围为 11 米（较初版扩大 37.5%），移动方向对应画面方向。
箱子持续白色外轮廓高光，包含箱顶笔记本电脑的轮廓。
靠近箱体表面 1.35 米以内可互动，列表包含武器、弹药和手雷，并显示名称、数量和价格。
每次进入游戏拥有 5000$ 初始资金，人物空手，两个武器槽位均为空；资金显示在 HUD、武器箱和背包中。
购买成功后扣除价格，依次装入第一个空闲武器槽位并立即持用；允许在两个槽位中购买同款武器。
资金不足或两个武器槽位已满时禁用购买并显示原因，不扣款、不替换已有武器；离开箱子或关闭列表也无法购买。
AK-47 初始价格为 2500$，手雷当前配置价格为 300$，均可通过独立武器维护工具修改。资金与装备为本局状态，重新进入游戏重置。
中型子弹：每份 250$，总弹药量固定为 40 发，购买时剩余弹药量为 40 发；每份独占下方 16 个小物品槽位中的一格，不合并堆叠。
手雷：购买价格由投掷物模板的 price 决定（当前配置为 300$/份），每份数量由 slotCapacity 决定（手雷 3 枚、震撼弹 2 枚）；购买后放入下方 16 个小物品槽位中的一格，不占用上方两个武器栏；物品格显示“剩余 / 每格数量”（如“3 / 3”），投掷一次减 1，格内用完才释放槽位。
手雷的伤害、范围、减速、减速时间、击退、引信、每格数量、物品场景和爆炸音效来自武器维护工具中的投掷物模板。
短按 G 拿出投掷物时，若正持枪，先按该武器的收回时间收枪，再用 0.35 秒把手雷从腰间拿到右手中；没有武器时直接拿出手雷。拿出手雷不会触发射击或占用两个武器栏。
手雷就绪后按鼠标左键，先用约 0.3 秒完成后摆蓄力、向前挥臂和释放动作；持雷时手雷位于身体右前方较远处，释放帧才从背包扣除并以右手位置生成。
投掷物轮盘：轮盘项目数等于背包中投掷物的种类数，同一种类的多个物品格合并显示总剩余枚数；打开时人物停止转向且不能开火，移动鼠标选择扇区，松开 G 拿出或切换选中种类。
投掷落点由鼠标指向的地面决定，最远约 18 米；手雷沿抛物线飞行、碰到地面或障碍物会弹跳，引信从投出时开始计时。
引信结束后在当前位置爆炸：范围内的每个目标都会收到完整伤害、减速倍率/持续时间和沿爆炸中心向外的击退；练习靶只应用伤害，减速和击退数据已交给命中接口供移动敌人使用。
投掷完成后自动按原武器的拿出时间重新取回之前收起的武器；没有武器时恢复空手。投掷途中、收枪途中或取枪途中不能开火、换弹、切枪或购买武器。
手雷在手中时短按 G 可取消投掷：手雷不消耗，按 0.25 秒收回后重新取出原武器；长按 G 打开轮盘可在不收回武器的情况下切换手持种类。
爆炸播放模板配置的音效并显示膨胀火球、冲击环和闪光；背包为空时不会生成手雷。
购买弹药不占用上方武器槽位。背包物品栏已满或资金不足时阻止购买，不扣款。
每份弹药独立记录剩余数量；物品槽显示“剩余 / 总量”，悬停或点击可查看两个属性。
中型子弹图标直接使用 assets/weapons/ammo/bullet_ak_triple.glb，在独立视口中渲染；所有同类物品和拖动预览共用一份图标纹理。
手雷图标使用投掷物模板的 itemScenePath（默认 assets/weapons/throwables/grenade.glb），同样在独立视口中渲染并共用预览纹理。
每份投掷物与弹药一样独立记录剩余数量；物品格显示“剩余 / 每格数量”，悬停显示每格数量与剩余枚数，购买不会合并到已有物品格。
背包内拖动保留物品实例、总量和剩余弹药，不拆分、不合并、不改变资金；拖到槽位外或武器槽位时取消，关闭背包也会取消未完成拖动。
调整位置后换弹按新的槽位顺序使用弹药。如果换弹在拖动期间耗尽该物品，会取消拖动，避免恢复已消耗的弹药。
新购武器弹匣为空；AK-47 使用中型子弹，弹匣容量由武器配置决定（默认 30 发）。两把同款武器独立保存弹匣余量。
换弹按物品槽顺序寻找匹配类型的弹药，可连续从多份物品补足弹匣；只消耗缺少的数量，备弹不足时仅装入现有数量。
弹药在动画完成时才扣除，剩余弹药量不会低于 0；用完的物品移除并释放原槽位，后续购买优先填入首个空槽。
弹匣已满或没有对应弹药时不开始换弹，并显示原因；切换或购买另一把武器会取消进行中的换弹，不消耗弹药。
HUD 显示当前武器的弹匣余量、容量和匹配的背包备弹；背包上方两个武器栏显示各自弹匣余量和容量。
HUD 在背包中有手雷时按剩余总枚数显示“手雷 ×N · G 短按拿出 / 长按选择”；手雷在手中时显示“手雷已就绪 · 左键投掷”，并隐藏当前武器的弹药信息。
购买后从武器配置的 scenePath 实例化武器场景，默认 scenes/weapons/AK47.tscn 引用 assets/weapons/rifle/AK47.glb。
空手时双臂自然下垂并随步伐摆动；持枪时右手握枪柄、左手托护木。
持枪实例比例：宽度 1.8、高度 1.2、长度 1.17；相比初版，枪身宽度加倍，长度增加 30%。
枪身相对放大后的初始持枪位置向前移 12 厘米，双手及换弹动作随握持点同步移动。
双臂沿长度方向延长 15%，关节与手掌握持点同步调整，原始模型文件不变。
身体纵向增高 25%，保留现有臂长，空手时双手离地；肩部、持枪位置、瞄准高度与碰撞体同步适配。
移动时双脚交替迈步，身体轻微起伏，双手持续贴合枪械；支持侧移和倒退。
换弹包含左手取出弹匣、装回弹匣及恢复持枪姿势；全程枪身保持正立不倾斜，也不拉动枪栓。
切换武器包含旧的收起和新的拿出动画：枪支与双手从持枪姿势旋转到下方收起位置，再旋转回持枪姿势；首次购买从空手姿势直接拿出。两段时长分别由武器属性控制。
FN-FAL 使用独立的持枪位置和换弹动画：枪身相对 AK 向右约 6 厘米、向后约 5 厘米，握把与护木手位按 FAL 模型对齐；弹匣竖直向下取出、竖直向上装回，不晃动。枪口使用模型的 MuzzleSocket。
已实现购买、两个槽位的装备切换、持枪、弹药装填和射击；每枪只消耗当前弹匣一发，HUD 与背包同步刷新。
射击使用武器的开火模式、冷却、散布及恢复、子弹速度、伤害和枪声音量；枪口闪光、轻微后坐与飞行曳光提供反馈。
子弹沿人物当前朝向水平飞行，随机偏转不超过当前散布半角；连续射击扩大散布，停火且经过冷却后恢复。
子弹逐物理帧检测完整飞行线段，只命中第一个目标或障碍物；枪口伸入障碍物时也不会穿墙。未命中子弹在 100 米或 5 秒后清理。
空手、空弹匣、换弹中、切枪过程中、投掷物拿取 / 收回 / 投掷过程中及打开商店/背包时不能射击；打开界面或切出游戏会取消持续开火，恢复后需重新按下左键。
三个练习靶位于初始位置前方，每个 100 点生命，命中闪烁并显示剩余生命；击倒后 3 秒恢复。准星随散布扩大，命中显示标记。
打开武器箱列表时不响应新的 R 键；已开始的换弹动作正常完成。
背包沿用现有深灰绿面板、圆角、细边框与中文字体：上方两个武器栏及配件位，下方 2 × 8 个物品格。
两个武器栏均根据实际购买结果显示内容，直接实例化 scenePath 武器场景，在独立 3D 视口中渲染；配件为空，物品栏显示购买的弹药。
背包关闭时停止预览渲染，打开时刷新；预览实例禁用游戏脚本，不参与实际玩法。
空武器槽的弹药数量以横线显示，已购买武器显示实际数量。
物品格支持悬停 / 点击查看栏位说明，也支持拖动移动和交换；弹药由换弹自动使用，不包含场景拾取。
背包与武器箱互斥，背包打开时不响应 E 互动和新的 R 换弹，适配最低 800 × 600 窗口。

独立武器维护工具
双击 RunWeaponEditor.cmd。这是独立的 Windows 桌面工具，不启动游戏，不在游戏内显示。
3D 预览在后台调用 Godot 读取武器场景网格，再由桌面界面的 Viewport3D 直接绘制。
预览支持拖动旋转、滚轮缩放、双击复位；切换场景或重新载入后刷新。
后台读取使用 GODOT_DOTNET 指定的引擎；未设置时使用本机 D:/godotCs 中的 Godot .NET。
资源需先在 Godot 中导入；引擎不可用时会显示预览错误，参数编辑仍可使用。
需要 .NET 10 SDK（启动脚本负责编译）和 Windows Desktop Runtime；本机已安装。
也可直接运行 tools/WeaponWorkbench/bin/Release/net10.0-windows/WeaponWorkbench.exe。
工具自动定位本工程，亦支持 --project "工程绝对路径"。

使用流程：左侧搜索或选择武器 → 编辑属性 → 保存全部（Ctrl+S）。
顶部“武器配置 / 投掷物模板”切换两类资源；切换时各自保留未保存草稿。
新增武器：点击左侧“＋ 新增武器”（Ctrl+N）→ 填写名称与分类 → 选择模型 → 调整属性和音效 → 保存全部。
新增投掷物：切到“投掷物模板” → 点击“＋ 新增投掷物”（Ctrl+N）→ 填写名称与分类 → 选择物品场景 → 调整爆炸属性、每格数量和音效 → 保存全部。
投掷物与武器共用左侧列表、搜索、未保存提示、撤销、备份和冲突检测；保存时两类资源一次写入 data/weapons.json。
新武器使用独立的初始参数和空音效配置；必须选择存在的武器场景后才能保存。可连续新增多个武器，切换时保留各自草稿。
新投掷物使用独立的初始参数（含每格数量 3 枚）和空音效配置；必须选择存在的物品场景后才能保存，爆炸音效可留空。
武器编号自动生成，也可在新增时修改，只能包含英文字母、数字、下划线或短横线，并且不能与其他武器重复；保存后编号固定。
“取消新增”移除当前尚未保存的新武器；已保存武器可编辑名称和分类。保存后重启游戏，新武器会出现在武器箱购买列表中。
“取消新增”同样移除当前尚未保存的新投掷物；已保存投掷物可编辑名称和分类。保存后重启游戏，新手雷会出现在武器箱购买列表中。
切换武器或投掷物都保留未保存草稿；红色字段会阻止保存，包括其他条目的无效草稿。
“撤销本武器修改 / 撤销本投掷物修改”恢复各自的保存值；重新载入及关闭窗口时，会询问如何处理未保存修改。
配置位于 data/weapons.json（schemaVersion 4），初始登记 AK-47 和手雷，可在维护工具中继续新增；原始模型资源保留供选择。
顶层 weapons 与 throwables 分别保存武器和投掷物模板；旧版 schemaVersion 4 没有 throwables 时按空列表载入，已有武器不受影响。
旧版投掷物模板缺少 slotCapacity 时按每格 1 枚载入，保持原来的单枚购买与消耗行为。
旧版配置需要将 schemaVersion 改为 4，并在每把武器的 stats 中添加 price 整数价格后使用；缺少价格时拒绝载入，避免意外免费购买。
AK-47 已有的调参数值保持不变；转动惯性默认系数为 10。
武器场景支持输入工程内 res:// 路径或“选择文件”，保存时检查路径、格式和文件是否存在。
武器场景路径参与未保存提示、撤销和保存；图标字段已移除，显示武器无需单独图片。
“05 武器音效”可选择或清空枪声，并添加、删除多条换弹音效；每条都有独立的“播放延迟 · 秒”。
投掷物模板使用“物品场景”和“爆炸音效”；物品场景同时用于背包图标和投掷物网格，必须存在。每格数量与购买价格同在“02 购买与使用”中编辑。
投掷物编号规则与武器相同，并在投掷物模板之间唯一；保存后编号固定。
枪声和每条换弹音效均可独立设置音量（0–200%），0% 静音、100% 原音量；支持小数，保存后重新启动游戏生效。
音效支持工程内的 WAV / OGG / MP3。先将文件放入工程，再使用“选择文件”；RunGame.cmd 启动时会导入新资源。
音效路径、列表、延迟与音量参与草稿、撤销、保存和备份；文件缺失、格式不支持、无效延迟或超出范围的音量会阻止保存。
投掷物的物品场景、爆炸音效、每格数量和全部数值同样参与草稿、撤销、保存、备份与冲突检测；物品场景必须存在，爆炸音效可留空。
保存使用临时文件原子替换，并在 data/weapons.json.bak 保留上一次完整配置。
文件在其他窗口被修改时会拒绝覆盖，可先保留需要的数值，再重新载入。
备份恢复：关闭维护工具后，将 .bak 文件复制覆盖 weapons.json，再重新打开工具。

属性定义（工具与游戏共用 scripts/Weapons/ 中的数据类型和校验规则）
枪声：武器的 gunshotSoundPath，留空表示静音；gunshotVolumePercent 控制音量百分比；每次成功射击播放一次。
换弹音效：武器的 reloadSounds 列表，每条包含 soundPath（音效路径）、delaySeconds（非负秒数）及 volumePercent（音量百分比）。缺少音量字段时默认 100%，保留旧配置的播放音量。
所有延迟从本次换弹开始计算，而非上一条音效结束后计算；0 为立即播放，相同延迟可以重叠播放，列表可按任意时间顺序填写。
例如延迟分别为 0、0.8、1.9，表示在换弹开始、开始后 0.8 秒、开始后 1.9 秒各播放一次。
成功开始换弹后按时间播放；缺少弹药、弹匣已满或重复按 R 不会重新触发音效。
切换武器会停止正在播放和等待中的换弹音效；下一次换弹重新计时。正常完成换弹不会截断音效，超过动画时长的延迟仍会按配置播放。
枪声或换弹音效未配置时保持静音；已有音效配置继续生效。旧版 schemaVersion 4 缺少这两个字段时默认静音。
对应弹药：ammoType，当前为 Medium（中型子弹），换弹仅使用该类型；武器维护工具可显示和保存此字段，旧版 schemaVersion 4 未写该字段时默认中型子弹。
购买价格：price，单位 $，范围 0–1000000 的整数；0 表示免费，仍需通过武器箱购买并占用武器槽位。
伤害值：单次命中的基础伤害，非负。
减速值：敌人移速降低百分比，0–100；不包含减速持续时间。
击退值：沿命中子弹方向施加的速度，单位米/秒，非负；命中数据携带该速度向量。
开火后冷却时间：两次射击的最短间隔，单位秒，至少 0.001；射速为 60 / 冷却时间（发/分钟）。
单发或连发：SemiAuto 为每次按下开火一次；Automatic 为按住持续开火，并遵循冷却时间。
弹夹容量：正整数。
换弹时间：reloadDuration，单位秒，可在“02 开火、装填与切枪”中设置，范围 0.001–3600；越小换弹越快，默认 2.65。
整段换弹动画按此时间等比例变速，包括弹匣、双手及枪身的轻微下沉；动画结束时才从背包扣除对应弹药并补充弹匣。
例如设为 1.325 秒时动画为原来的 2 倍速，设为 5.3 秒时为原来的半速。移动和转向速度不受影响。
本次换弹开始时确定时长，重复按 R 不会重置；切换武器会取消，下次换弹使用新武器的配置。
旧版 schemaVersion 4 未设置 reloadDuration 时保留 2.65 秒。音效延迟仍按每条 delaySeconds 的实际秒数执行，可独立调整。
切枪 / 拿出武器时间：equipDuration，单位秒，范围 0.001–3600，默认 0.35；从下方收起位置旋转到持枪姿势的时长，越小拿出越快。
收回武器时间：holsterDuration，单位秒，范围 0.001–3600，默认 0.25；从持枪姿势旋转到下方收起位置的时长，越小收回越快。
切换武器时先按旧武器的 holsterDuration 收起，再按新武器的 equipDuration 拿出；两段总时长就是完整切枪时间。
动画播放期间不能开火、换弹或再次切换；切换完成时新枪准确回到持枪姿势。旧版 schemaVersion 4 未设置这两个字段时使用 0.35 / 0.25 秒。
移动惯性：这里定义为持枪移动速度惩罚百分比，0–100；速度 = 基础速度 × (1 - 惯性 / 100)。
转动惯性：turnFollowSpeed，是乘在 delta 上的跟随系数 k，范围 0–1000，默认 10。
每帧按 LerpAngle(当前朝向, 鼠标目标朝向, 1 - Exp(-delta * k)) 沿最短角度平滑跟随。
角度差越大，每帧转过的角度越大；系数越大跟随越快；0 表示不转向，不是瞬间转向。
该公式使用帧间隔，30/60/120 FPS 下对固定目标的跟随速度一致；打开界面时仍停止转向。
子弹飞行速度：米/秒，必须大于零。
子弹散布最大值 / 最小值：偏离瞄准方向的半角，单位度，0–180，最小值不能超过最大值。
子弹散布增加值：每开一枪增加的角度，单位度/发，增加后不超过最大值。
散布减少值：度/秒；最后一枪经过冷却时间后开始下降，不低于最小值；0 表示不恢复。
散布恢复计算只使用当前帧位于冷却结束后的时间，避免跨冷却边界提前恢复。
武器场景：scenePath，支持 TSCN / SCN / GLB / GLTF，根节点必须为 Node3D；购买或切换武器时加载为持有武器。
默认场景保留现有 AK 的弹匣、换弹及拿出 / 收回表现，换弹时枪身不倾斜、不拉枪栓；FN-FAL 使用独立持枪偏移、直弹匣换弹和 MuzzleSocket 枪口。替换自制模型时需自行匹配握持点及比例。
武器场景根节点下可放置名为 Muzzle 的 Marker3D 定义枪口；未提供时使用默认 AK 枪口位置，朝向仍跟随人物。
背包和维护界面均通过 scenePath 展示武器 3D 模型；itemScenePath 同时用于背包图标和投掷物网格；所有同类物品和投掷物共用一个预览纹理。
桌面维护预览读取网格和基础材质颜色；自定义着色器效果以 Godot 游戏内预览为准。

投掷物模板属性（工具与游戏共用 scripts/Weapons/ThrowableDefinition.cs）
购买价格：price，单位 $，范围 0–1000000 的整数；0 表示免费。价格为每份价格：一次购买把一格填满“每格数量”枚，只扣一次 price。
每格数量：slotCapacity，范围 1–1000 的整数，默认 1；一个物品槽位可容纳并一次放入的枚数，与子弹的每份数量相同。投掷一次减 1，格内用完才释放槽位。
伤害值：damage，爆炸范围内每个目标受到的基础伤害，范围 0–1000000；范围内不做距离衰减。
范围：range，爆炸作用半径，单位米，范围 0.1–1000。
减速值：enemySlowPercent，爆炸后敌人移速降低百分比，0–100；降低后的倍率为 1 - 减速值 / 100。
减速时间：slowDuration，单位秒，范围 0–3600；随命中数据传给 IProjectileTarget 的 SlowDuration。
击退值：knockbackSpeed，单位米/秒，范围 0–10000；方向从爆炸中心指向目标（去掉垂直分量）。
引信时间：fuseTime，单位秒，范围 0.05–3600；从手雷投出时开始计时，飞行中也会继续倒计时。
物品场景：itemScenePath，支持 TSCN / SCN / GLB / GLTF，根节点必须为 Node3D；同时用于背包图标和投掷物网格。
爆炸音效：explosionSoundPath，支持 WAV / OGG / MP3；留空表示静音。引信结束时在爆炸位置播放一次。
手雷在手中时按左键投掷；短按 G 收起且不消耗，长按 G 打开轮盘切换种类。落点由鼠标指向的地面决定，最远约 18 米；手雷按抛物线飞行并与地面/障碍物弹跳，引信结束后在当前位置爆炸。
爆炸使用球形查询，范围内的所有 IProjectileTarget 都会收到同一份伤害、减速倍率/持续时间与击退速度。

游戏启动时读取这份配置作为武器箱商品列表，购买后将属性应用到当前持有武器，手雷则按每格数量成叠进入物品槽位。
射击、飞行子弹、碰撞与练习靶伤害已实现。命中接口 IProjectileTarget 接收发射时保存的伤害、减速倍率、减速持续时间和击退速度；当前静止练习靶只应用伤害，移动敌人的减速/击退行为尚未添加。
保存后需重启游戏读取新值，不会在后台改变已经运行中的游戏。
导出游戏时，需要将 data/*.json 加入非资源文件导出过滤器。
